Problemas del Calculista

Algoritmos interactivos con formularios, DOM y JavaScript

1. El reparto de los panes

Descripción: Dos viajeros aportan panes para comer por igual con un forastero, que paga 8 monedas de plata por su parte. Se reparten las monedas en proporción justa.

Algoritmo:

  1. Cortar cada pan en 3 porciones y sumar los panes de ambos.
  2. Calcular cuánto come cada persona y cuánto le aporta cada viajero al forastero.
  3. Repartir las 8 monedas según ese aporte.

Entrada: panes de cada viajero. Salida: monedas justas para cada uno.

2. El reparto de los camellos

Descripción: Una herencia de camellos debe repartirse en partes de 1/2, 1/3 y 1/9. Se buscan camellos auxiliares hasta llegar a un múltiplo de 18 para que las fracciones salgan exactas.

Algoritmo:

  1. Leer la cantidad de camellos.
  2. Sumar camellos auxiliares hasta el siguiente múltiplo de 18.
  3. Calcular las tres partes y el sobrante.

Entrada: camellos iniciales (entero). Salida: total ajustado, partes de los hermanos y ganancia del calculista.

3. Estimación del valor de Pi

Descripción: Se estima π con la fórmula π ≈ √(6 · Σ 1/n²), sumando los inversos de los cuadrados con un bucle.

Algoritmo:

  1. Leer el límite n.
  2. Con un bucle, acumular la suma de 1/k² para k de 1 a n.
  3. Multiplicar por 6 y sacar la raíz cuadrada.

Entrada: entero n (por ejemplo 100, 10000 o 1000000). Salida: valor estimado, valor real y diferencia.

4. Raíces de una ecuación cuadrática

Descripción: Se hallan las raíces reales de ax² + bx + c = 0 con el discriminante D = b² − 4ac.

Algoritmo:

  1. Leer a, b y c.
  2. Calcular D.
  3. Si D > 0 hay dos raíces; si D = 0 hay una; si D < 0 no hay raíces reales.

Entrada: números a, b y c (a distinto de 0). Salida: mensaje y raíces calculadas.
